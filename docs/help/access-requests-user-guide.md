# Access requests

Not everything can be open. When a file is kept back, by its availability, its rights, an embargo or a security classification, a researcher can ask for access, and someone with the authority decides.

## Asking

On a record's page in the catalogue, **Ask for access to these files** opens the request form; **New request** under **Research**, **Access requests** asks without starting from a record. The request says:

- what it is for: to view restricted material, to have copies, permission to publish, research access, or other;
- its scope: a single item, a collection, or everything;
- why access is needed, and how urgently;
- for how long.

**My requests** (`/access-requests/mine`) lists your own requests and where each stands. A request not yet decided can be cancelled.

## Deciding

**Access requests** (`/access-requests`), for those who may review them, lists every request waiting, with who asked and what for. Open one to **approve** it for a number of days, with a note if you like, or **deny** it with the reason, which is required. The person who asked is sent an e-mail either way.

An approved request opens the files it covers to that person, until it ends. When it ends, its status becomes expired and the files close again.

## How it fits with the rest

An access request is the way through what [rights](/help/article/rights-management-user-guide), [embargoes](/help/article/embargo-user-guide) and [security clearance](/help/article/security-clearance-user-guide) keep closed. It opens the files to one person; it never changes what the public sees. To open something to everyone, change the right or lift the embargo.
