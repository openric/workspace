# Citing a record

Every published unit of description can be cited from its page: choose **Cite**, or **Cite as** in the public catalogue (`/cite/{record}`).

## Styles

The citation is shown ready to copy in:

- **Chicago 17**, **APA 7**, **MLA 9**, **Harvard** and **Turabian**;
- **ISAD(G)**, the archival form: repository, reference code, title, dates and level.

Each gives the institution, the reference code, the title, the dates and the record's persistent IRI, so the citation leads back to the record for as long as the institution keeps it.

## Reference managers

The same citation downloads as a file to import into a reference manager:

| Format | For |
|---|---|
| RIS | Zotero, Mendeley, EndNote and most others |
| BibTeX | LaTeX |
| EndNote XML | EndNote |
| CSL-JSON | Zotero and any CSL processor |

## Why the IRI matters

A URL in a browser's address bar can change when a website is rebuilt. The persistent IRI does not: it is the record's name in RiC, kept for ever, and if the record is withdrawn it says so and where to go instead. Cite the IRI.

## Citations counted

The institution sees which records are cited, how often and in which format, as part of its research analytics. A citation by a signed-in user is logged against their account; a visitor's is counted without one.
