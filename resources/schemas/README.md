# Schemas

Copies of the published XML schemas that the export formats are checked against (tests/Feature/ExportTest). They were fetched on 20 October 2026, and their `schemaLocation` imports were pointed at the copies here so validation needs no network.

| File | Schema | Source |
| --- | --- | --- |
| ead2002.xsd | EAD 2002, W3C schema, release 20210412 | https://www.loc.gov/ead/ead.xsd |
| ead3.xsd | EAD3 1.1.1 (2019-12-16) | https://www.loc.gov/ead/ead3.xsd |
| xlink.xsd | XLink attributes as used by EAD 2002, MODS and METS (Library of Congress) | https://www.loc.gov/standards/mets/xlink.xsd |
| mods-3-8.xsd | MODS 3.8 | https://www.loc.gov/standards/mods/v3/mods-3-8.xsd |
| oai_dc.xsd | OAI-PMH Dublin Core container | https://www.openarchives.org/OAI/2.0/oai_dc.xsd |
| simpledc20021212.xsd | Simple Dublin Core elements (DCMI) | https://dublincore.org/schemas/xmls/simpledc20021212.xsd |
| xml.xsd | The xml: namespace (W3C) | https://www.w3.org/2001/xml.xsd |
| OAI-PMH.xsd | OAI-PMH 2.0 protocol responses | https://www.openarchives.org/OAI/2.0/OAI-PMH.xsd |
| oai-identifier.xsd | OAI-PMH 2.0 oai-identifier description | https://www.openarchives.org/OAI/2.0/oai-identifier.xsd |

Each schema remains under its publisher's terms. They are bundled unchanged except for the import locations.
